# Assessing Generalization in AI-Generated Music Detection

Supplementary results for the ICASSP 2027 submission: the paper's tables broken down by family exclusion, generator, training-test pair, human-made pool and decision threshold.

All values are recomputed from the saved per-recording scores of the detectors evaluated in the paper. No model was refitted. The rows printed in the paper are reproduced before any table is written.

- `index.html`: the page, self-contained
- `data/companion_data.json`: all values, unrounded, with the checksum of every input file
- `data/*.csv`: one file per table

Hosted with GitHub Pages from the repository root.
